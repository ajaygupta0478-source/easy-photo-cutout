# Easy Photo Cutout

A simple installable web app for Android and Windows.

## Publish
Enable GitHub Pages from the repository settings and select the `main` branch with the `/(root)` folder. The app will then be available over HTTPS.

## Install
- Android: Open the HTTPS app link in Chrome, then choose **Install app** or **Add to Home screen**.
- Windows: Open the HTTPS app link in Microsoft Edge or Chrome, then use the browser's **Install this site as an app** option.

## Features
- Select a photo
- Remove background in-browser using an AI model
- Preview transparent cutout
- Choose a solid background or upload a background photo
- Download transparent PNG or JPG

The first background-removal run downloads the AI model and requires an internet connection. Processing is performed in the browser.
